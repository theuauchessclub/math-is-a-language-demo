# Math Is a Language: classroom demo

A password-free, single-browser demonstration of the Lesson 3 classroom interface. It is separate from the protected classroom application and has no database connection.

## Try the classroom workflow

- Open Teacher demo for Daily View, Gradebook, scoring and feedback, participation, Community Circle and the roster.
- Switch to a student-initial role to try the opener, notes, classwork and exit ticket, including multipart graph questions.
- Switch back to Teacher demo to inspect the test work entered in this browser.
- Local solo and team review games are available. The scaffold example is a separate fictional role.
- Export local results as CSV, or reset this demo's saved browser data.

## What the data means

The nine initials-only labels come from the teacher-provided Period 5 roster snapshot. They do not confirm current enrollment. All assignments and results are demonstration data; results start blank. There are no surnames, attendance IDs, imported grades, teacher records, recordings, passwords or service credentials in this package.

Everyone can open teacher tools. Work is stored only in the current browser profile, not submitted to a teacher and not synchronized across devices. Other people using that browser profile can read or change it. Do not enter real grades, personal information or sensitive Circle responses. Clearing browser data can erase the demo; exported files remain outside it.

Attendance integration, roster editing/import, microphone recording, cloud audio storage, protected teacher access and network multiplayer are not enabled. This demo is not a production student reporting system.

The application sends no classroom responses or scores to a server. GitHub serves the static files and may process ordinary website-request metadata under its own policies. School-device access depends on the district's website policy and must be tested on an actual permitted device.

## Content attribution

The lesson retains the source acknowledgments and CC BY 4.0 attribution for the referenced Illustrative Mathematics / Kendall Hunt materials. The exit ticket and classroom adaptations are identified in the lesson. School branding is separate from those curriculum materials.
